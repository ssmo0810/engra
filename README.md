# engra

교대 근무 인수인계를 데이터가 먼저 쓰고, 사람이 마무리하는 AI 서비스.

**데모 페이지 →** https://<아이디>.github.io/engra

---

## 한 문장 정의

12시간 근무 구간의 운전 데이터를 AI가 읽고 특이사항 초안을 작성해, 다음 근무조에게 기억이 아닌 기록으로 인계합니다.

## 문제

24시간 연속 공정은 12시간 2교대로 운영됩니다. 제어시스템은 수백 개 태그를 초 단위로 기록하지만, 다음 조에게 넘어가는 것은 근무자의 기억에 의존한 수기 일지 몇 줄입니다.

- 기록 기준이 사람마다 달라 같은 현상이 조마다 다르게 남거나 아예 남지 않습니다.
- 알람 임계값을 넘지 않은 이상 징후(순도 헌팅, 온도 드리프트)는 기록될 이유를 얻지 못합니다.
- 근무 초반의 미세한 변화는 일지를 쓰는 시점에 이미 흐려져 있습니다.

## 작동 방식

1. **데이터 일괄 분석** — 고정 임계값이 아니라 태그별 평소 패턴과 비교해 조용히 벗어난 구간을 찾습니다.
2. **초안 생성 (교대 1시간 전)** — 발생 시각, 추이 차트, 과거 유사 사례의 조치 코멘트를 붙인 초안을 준비합니다.
3. **선택 · 보완 · 승인** — 근무자가 채택할 항목을 고르고 현장 맥락을 덧붙입니다. 최종 판단은 사람이 합니다.
4. **축적 · 질의** — 승인된 일지가 쌓여 "이 증상, 과거엔 어떻게 조치했나?"에 답하는 근거가 됩니다.

## 목표치

| 항목 | 목표 |
| --- | --- |
| 특이사항 포함률 | 90% 이상 |
| 초안 자동 생성 시점 | 교대 60분 전 |
| 기록 기준 표준화 | 100% |

실측값이 아닌 서비스 목표치입니다. 데모 페이지의 화면·수치·태그는 모두 가상 데이터입니다.

## 확장 로드맵

- **Phase 1** 단일 공정 파일럿 — 한 개 라인의 2교대에 적용해 초안 정확도와 채택률 측정
- **Phase 2** 공장 단위 확대 · 질의 검색 — 축적된 일지를 근거로 과거 조치 검색·인용
- **Phase 3** 비공정 업무 인수인계 — 데이터가 남는 모든 업무로 확장
