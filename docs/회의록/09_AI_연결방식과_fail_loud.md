## 논의
- 초안 문장을 AI 가 쓴다. 붙이는 방법이 두 가지다 — **API 키** vs **CLI 서브프로세스**.
- CLI 는 비용이 들지 않지만 **사람 노트북에 의존**한다. 교대 1시간 전 자동 실행이 성립하지 않는다.
- API 는 서버에서 무인 실행이 되지만 키를 어디에 두느냐가 남는다.
- **AI 가 없으면 어떻게 할까.** 조용히 문장 틀로 내려가면 화면은 정상처럼 보인다.
  → 그게 더 위험하다. 심사에서도 「AI 없이도 되는 것 아닌가」로 읽힌다.

## 결정
- **런타임은 서버에서 HTTP API 무인 실행.** 개발·튜닝은 CLI 어댑터로 한다(비용 0),
  어댑터가 완성되면 API 로 1회 통과시켜 둔다.
- **AI 는 필수로 둔다.** 키가 없으면 **초안 생성을 거부하고 이유를 화면에 표시**한다.
  끄려면 명시적 플래그를 주고 화면에 **「AI 미연결」 배지**를 띄운다. 조용히 대체하지 않는다.
- **AI 가 맡는 범위** — ① 서술 ② 중요도 판정 ③ 사례 적합성 ④ 의미 단위 묶음.
  **후보 추출에는 넣지 않는다**(재현성·설명가능성).
- **프롬프트로 지시한 것과 모델이 스스로 판단한 것을 구분해 기획서에 적는다.**
  외기 제외처럼 프롬프트에 명시한 것은 학습이 아니라 지시 이행이다.
