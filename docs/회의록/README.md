# 회의록

**주 2회**, 굵직한 결정이 있는 날만 남긴다. 회의마다 **팀원 세 사람이 안건 하나씩** 들고 온다.

작은 조율은 이슈로 처리하고 여기 안 적는다 — 회의록이 많아지면 무엇이 중요한 결정이었는지가
묻힌다. 판단이 뒤집힌 것은 뒤집힌 대로 적는다(회의 04 의 LLM 연결 방식이 그 예다).

## 쓰는 규칙

- **안건 하나에 결정 3~5줄.** 배경은 판단이 갈렸던 지점만 적는다
- **뒤집힌 판단을 지우지 않는다.** 왜 뒤집었는지가 04 제작 과정의 재료다
- 회의에서 정한 것과 나중에 이슈에서 바뀐 것이 다르면 **이슈 쪽이 최신**이다
