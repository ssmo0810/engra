## 논의
- 5분 영상. 화면부터 보여주면 **무슨 문제를 푸는지 전달되지 않는다.** 앞에 소개가 필요하다.
- 소개를 기존 소개 페이지로 쓰기엔 분량이 많다(12개 섹션, 낭독 3분 초과). **영상 전용 한 화면**을 따로 만든다.
- 화면 글자와 내레이션이 같은 말을 하면 보는 사람이 읽느라 듣지 않는다. 화면엔 **구조와 숫자만** 둔다.

- **구성** — 앞 **40초** 소개 화면 → 우측 하단 「파이프라인 열기」 버튼으로 라이브 앱 전환 →
  나머지 약 4분 실제 화면 시연(업로드 → 검출 → AI 초안 → 승인 → **다음 근무에서 과거 조치 회수**).

- **촬영** — 맥북 **화면 녹화**, 녹음은 맥북 **내장 마이크**. 배속·컷 없이 실시간.
- **일정** — **9/2(수) 퇴근 후 19:30 집합.** 장소는 인근 카페 섭외 중.
- 공개 데모 서버에서 녹화하지 않는다. 승인 대기를 소모해 다음 방문자가 흐름을 못 본다. **로컬로 녹화.**
