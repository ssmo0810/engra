## 0. 첫 질문이 될 확률이 높은 것 (Q&A 5분의 첫 2개)

1. **본선 심사평에서 지적된 것을 결선 하루 동안 무엇을 어떻게 고쳤나?** — 평가 4축 중 하나가 통째로 이것. 미션지를 받은 뒤 답이 정해진다.
2. **AI를 빼면 무엇이 안 되나? 통계 검출만으로 되는 것 아닌가?** — "AI 네이티브" 축. 기획서 3-5 표(AI가 하는 일 6단계·사람이 남는 자리)가 답의 뼈대.
3. **실제 현장에 붙이려면 무엇이 더 필요하고 얼마나 걸리나?** — 6-3 3층 표(1층 어댑터 1개·2층 태그 명세). 3일에 53점 정의한 실측.

## 1. 임팩트 — SK그룹에 만드는 변화

4. 인수인계 누락으로 실제로 어떤 사고·손실이 있었나? 숫자로 말할 수 있나? (사내 데이터라 못 쓴다면 어떻게 답할지 정해 둘 것)

7. 이 시스템이 없어도 숙련 운전원은 이미 잘 하고 있지 않나? 신입에게만 필요한 것 아닌가?
8. 안전 관련 판단을 AI 초안에 의존하게 되면 오히려 위험해지는 것 아닌가? (자동화 편향)

## 2. AI 네이티브 — AI가 중심에 있나

13. 환각 0건은 "숫자 필드가 없어서"인데, 그건 AI를 믿어서가 아니라 못 믿어서 막은 것 아닌가?

15. 모델이 바뀌면(Opus→다른 모델) 결과가 달라지나? 재현성 9/9는 같은 모델에서만 잰 것 아닌가?
16. 과거 조치 회수가 "같은 태그"만 본다 — 증상이 같은데 태그가 다르면 놓치는 것 아닌가?
17. 프롬프트에 "외기를 정상으로 봐라"를 넣었다는 건 규칙 하드코딩 아닌가? 새 유형이 나오면?
