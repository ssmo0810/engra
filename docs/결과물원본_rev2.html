결과물 원본 — 접속 주소와 공개 설정

설치할 것이 없습니다. 브라우저로 열면 실제로 동작하는 프로토타입이고, 심사위원이 직접 승인 버튼을 눌러 확정 일지가 만들어지는 것까지 확인하실 수 있습니다.

1.작동하는 앱 — 바로 조작할 수 있습니다

접속 주소
https://engra.64-176-227-85.sslip.io

로그인·설치 없이 열립니다. HTTPS 상시 실행이며 외부 익명 접근으로 200 응답을 확인했습니다 실측

1-1. 어디를 보면 되나

주소무엇을 볼 수 있나
/ 확정된 인수인계 일지 목록. 근무별로 무엇이 인계됐는지 조회합니다
/shift/<근무ID> 초안 검토 화면. 감지된 항목이 중요도 순으로 놓여 있고, 항목마다 태그·시각·수치 근거와 추이 파형, AI 중요도 판단 이유, 같은 태그의 과거 조치가 함께 보입니다. 채택·제외를 고르고 코멘트를 달아 직접 승인하실 수 있습니다
/pipeline 빈 상태에서 시작하는 전 과정 — CSV 업로드 → 적재·검출 → AI 초안 → 검토·확정
/dcs · /rtdb 모의 DCS Overview(태그 53점 미믹·데이터 생성기)와 RTDB 조회 화면
/api/shifts
/api/draft/<근무ID>		 근무 목록과 초안을 JSON 으로. 화면을 거치지 않고 결과를 확인하실 때 씁니다

1-2. 이것만 보시면 이 서비스의 핵심이 보입니다

승인 대기 상태의 근무를 열어 항목을 채택·제외하고 코멘트를 달아 승인해 보십시오. 확정 일지가 만들어집니다. 그리고 그 일지의 코멘트는 다음 근무 초안에 「과거 조치」로 되돌아옵니다 — 사람의 판단이 저장되었다가 다시 AI 의 입력이 되는 순환이 이 서비스의 핵심이고, 승인 대기 근무의 초안에서 이미 그 결과를 보실 수 있습니다.

모든 값은 가상 데이터입니다. 사내 원본 데이터·실제 태그 체계· 시스템 화면을 일절 사용하지 않았습니다. 태그는 AI-707 같은 가상 표기이고, 수치는 형태만 실제와 유사하게 잡은 모의 데이터입니다.

curl -s -o /dev/null -w "%{http_code}\n" https://engra.64-176-227-85.sslip.io/

3.안 열릴 때 — 동봉한 소스로 로컬에서 실행

서버 사정으로 주소가 열리지 않을 경우를 대비해 소스 스냅샷을 이 폴더에 함께 올렸습니다. 저장소가 규정에 따라 비공개라(4장), 운영진 안내 없이도 코드를 열어 보고 직접 실행하실 수 있게 한 것입니다.

동봉 파일
소스스냅샷_engra_<커밋>_앙그라쥬.zip

파일 이름에 어느 커밋을 뜬 것인지가 들어 있습니다. 마감 직전 최신 커밋으로 다시 만들어 올리므로, 압축을 풀면 심사 시점의 앱과 같은 코드입니다. 원본 시계열(data/)은 「03. 데이터 세트」에 따로 올라가 있어 zip 에서는 제외했습니다.

3-1. 실행 방법 — 설치할 것이 없습니다

파이썬 3.10 이상만 있으면 됩니다. 통계 분석과 검출 알고리즘, 서버, 화면을 모두 표준 라이브러리로 직접 구현해 외부 의존이 0입니다 — 의존성 선언 파일이 없고, 설치 명령도 없습니다 실측

  1. zip 을 풀고 그 폴더로 이동합니다.
  2. 아래 한 줄로 배선 전 구간(저장소 생성 → 적재 → 검출 → 초안 → 승인 → 확정 일지 → 재실행 차단까지 11단계)이 한 번에 도는 것을 확인합니다.
bash tools/smoke.sh
  1. 화면으로 보시려면 서버를 띄우고 브라우저로 접속합니다.
python3 app/cli.py serve --host 127.0.0.1 --port 4320
# 브라우저에서 http://127.0.0.1:4320
  1. QA 에서 실제로 터졌던 결함을 고정한 회귀 시험 36건도 함께 돌려보실 수 있습니다.
python3 tests/test_regressions.py
같은 입력에 같은 결과가 나옵니다. 모의 데이터는 seed 를 고정했고 근무 식별자는 날짜 인자로 고정했습니다. 통계 기반 검출을 택한 이유이기도 합니다 — 판정 근거를 그대로 제시할 수 있고 재현이 성립합니다.

4.저장소 주소와 공개 설정

소스 저장소
https://github.com/ssmo0810/engra

공개 설정 — 비공개(Private)

대회 규정이 저장소를 비공개로 두도록 요구하고 있어 익명 접근은 차단됩니다. 규정을 지키기 위한 설정이며 공개로 되돌리지 않습니다. 심사위원 열람이 필요하신 경우 운영진 안내에 따라 제공하겠습니다 — 저희가 임의로 초대하지 않습니다.

그래서 위 3장의 소스 스냅샷 zip 을 함께 올렸습니다. 저장소에 접근하지 않으셔도 코드 전체를 보시고 직접 실행하실 수 있습니다.

항목내용
공개 설정비공개 — 대회 규정 준수

비밀 정보포함되지 않습니다. zip 을 만들 때 .env·인증서·개인키가 섞이면 생성이 중단되도록 검사를 걸어 두었습니다
외부 라이선스 의무없습니다. 외부 라이브러리를 쓰지 않아 서드파티 라이선스 의무가 발생하는 구성요소가 없습니다
사내 정보사내 원본 데이터·실제 태그 체계·시스템 화면·계정 정보가 코드와 데이터 어디에도 없습니다

요약 — 접속 주소는 https://engra.64-176-227-85.sslip.io 이고 외부에서 로그인 없이 열립니다(익명 200 확인). 열리지 않을 경우 이 폴더의 소스 스냅샷 zip 을 풀어 파이썬만으로 실행하실 수 있습니다. 저장소 ssmo0810/engra 는 규정에 따라 비공개입니다. 자세한 사용법은 「02. 결과물 / 3. 설명서·매뉴얼」에, 검증 절차와 결과는 「03. 데이터 세트」에 있습니다. 이 문서의 확인 기준일은 2026-09-01 이며, 제출 직전에 주소가 열리는 것을 다시 확인합니다.
