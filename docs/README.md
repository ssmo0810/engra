# docs — 시나리오 · 모의 데이터 (임도영)

ENGRA 데모용 **가상 ASU(공기분리장치) 플랜트**의 특이 시나리오 정의, 모의 DCS 화면, 태그 마스터입니다.

> **모든 값은 가상입니다.** 사내 실제 태그 체계, 운전값, 시스템 화면과 무관하게 작성했습니다.

## asu_dcs_overview.html 사용법

브라우저로 열면 상단에 두 개의 탭이 있습니다.

- **OVERVIEW PAGE** — ASU 공정 미믹 화면. 설비, 배관(AIR·GN2·LIN·LOX), 컨트롤 밸브, 계측 태그 53점을 배치했습니다.
- **DATA DETAIL** — 태그 마스터 편집 화면.
  - 태그별 **정상값 / 정상범위 / LL·L·H·HH 알람한계**를 입력합니다.
  - **드리프트·노이즈를 1~3단계**로 선택합니다. 태그명을 클릭하면 우측에 60분 파형이 즉시 그려집니다.
  - **연동 태그**란에 상관관계를 적습니다. 형식은 `대상태그:이득:지연초` 입니다.
  - `베이스라인 생성` 버튼으로 raw data(CSV)를 뽑습니다. **누를 때마다 새 랜덤 데이터**가 나오고, 우측 미리보기도 방금 만든 데이터로 맞춰집니다.

## 태그 명명 규칙

**접두 알파벳** — `T` 온도 · `P` 압력 · `PD` 차압 · `F` 유량 · `L` 레벨 · `A` 분석(순도·O₂) · `M` 수분 · `Z` 밸브개도 · `S` 회전수 · `J` 전력

**번호 블록 (3자리, 앞자리가 설비 구분)**

| 블록 | 설비 |
|---|---|
| 100 | Air Filter (F-101) |
| 200 | Air Compressor (K-201) · Motor (M-202) |
| 300 | Adsorber A/B (A-301 / A-302) |
| 400 | Main Heat Exchanger (E-401) |
| 500 | Turbine (X-501) · Generator (G-502) |
| 600 | Cold Box Inlet (FV-601) |
| 700 | HP/LP Column (C-701 / C-702) · 이송밸브 (FV-709) |
| 800 | LOX Tank (TK-801) · LIN Tank (TK-802) |
| 900 | GN2 Supply (PV-902) · Vent (PV-903) |

같은 제어 루프는 번호를 공유합니다. 예: `FV-601`(밸브) ↔ `ZI-601`(그 밸브의 개도).

**단위** — 압력 `bar` · 온도 `℃` · 개도 `%` · 유량 `Nm3/h` · 전력 `kW` · 분석 `ppm` · 회전수 `rpm`

## 베이스라인 데이터 생성 방식

정상 운전 데이터는 세 겹으로 만듭니다.

1. **기저값** — 태그별 정상 운전값
2. **드리프트** — 20~60분 주기의 완만한 흔들림 (외기·부하 변동 반영)
3. **측정 노이즈** — 태그별 σ

드리프트·노이즈 크기는 정상범위 폭 대비 비율로 정합니다.

| 단계 | 드리프트 | 노이즈 |
|---|---|---|
| 1 | 2% | 0.5% |
| 2 | 6% | 1.5% |
| 3 | 12% | 3.5% |

노이즈 없는 선형 데이터를 쓰면 이상 탐지가 실제보다 쉬워 보이므로 의도적으로 배제했습니다.

## 태그 간 연동 (물리 제약)

태그가 서로 무관하게 움직이면 현장 관점에서 부자연스럽고, 시나리오의 연쇄 반응도 표현되지 않습니다. 주요 연동 관계를 정의해 두었습니다.

| 원인 | 결과 |
|---|---|
| `ZI-601` 개도 ↑ | `FI-602` 유량 ↑ , 20초 후 `PI-604` 압력 ↓ |
| `ZI-709` 개도 ↑ | `FI-710` 이송유량 ↑ , 60초 후 `LI-701` ↓ , 90초 후 `LI-705` ↑ |
| `PDI-303` 차압 ↑ | 5분 후 `MI-302` 후단 수분 ↑ (흡착제 파과 징후) |
| `AI-707` LP 순도 ↓ | 3분 후 `AI-803` LOX 탱크 순도 ↓ |
| `PI-203` 토출압 ↑ | `JI-206` 소비전력 ↑ , `TI-205` 토출온도 ↑ |
| `ZI-905` Vent 개도 ↑ | `FI-906` 벤트유량 ↑ , 20초 후 `PI-901` 공급압 ↓ |

## 외기 연동 — 하루 흐름 (2026-08-26 추가)

ASU는 대기 온도·습도에 공정 전체가 끌려갑니다. 태그가 각자 무작위로 흔들리면 하루 흐름이 없어 부자연스러우므로, **`TI-101` 대기온도와 `MI-102` 대기습도를 뿌리로 두고 하류 태그가 따라 움직이게** 했습니다.

**외기 자체 (여름 기준 일주기)**

| 태그 | 최저 | 최고 | 위상 |
| --- | --- | --- | --- |
| `TI-101` 대기 온도 | 24℃ (05시) | 33℃ (15시) | — |
| `MI-102` 대기 습도 | 55% (15시) | 82% (05시) | 온도와 **역위상** |

실제 일교차는 상승 10시간·하강 14시간으로 비대칭이므로, 반코사인 두 구간을 이어 붙였습니다. 단순 사인파를 쓰면 최저·최고가 정확히 12시간 간격이 되어 새벽 최저·오후 최고가 안 맞습니다.

**외기 영향을 받지 않는 태그**

- **탱크 계통** — `ZI-801` · `ZI-805` · `LI-802` · `AI-803` · `MI-804` · `LI-806` · `AI-807` · `MI-808`
  탱크는 단열 저장 설비라 외기 영향이 미미하고, 인입 밸브 개도는 출하 스케줄로 결정됩니다.
  단 `AI-803`은 **`AI-707` 경유 간접 경로는 살려 뒀습니다.** 생산 순도가 나빠지면 탱크로 들어가는 제품 순도도 나빠질 수밖에 없어, 이 경로를 끊으면 두 값이 어긋나게 움직입니다.
- **제어로 유지되는 것** — `PI-203` 토출압력, `PI-604` · `PI-502` · `PI-504` 압력, `LI-701` · `LI-705` 컬럼 레벨, `SI-507` 회전수.
  제어기가 목표값을 지키므로 값 자체는 거의 그대로고, 대신 **개도와 전력이 움직입니다.**

**감도 관리** — 태그 마스터 표의 `외기T` · `외기H` 두 열입니다. 각 태그가 자기 행에 "나는 온도에 0.7, 습도에 0.2 반응한다"를 적습니다. 연동 태그와 같은 정규화 방식이라 값의 의미가 일관됩니다. 비어 있으면 외기 영향 없음입니다.

**적용 순서** — 베이스라인 → 시나리오 주입 → 태그 간 연동 → **외기 전파** → 값 고정·스파이크 덮어쓰기 → 물리 한계 클램프

외기를 연동 **이후**에 적용합니다. 그래야 감도값이 그 태그의 **순 일변동**을 그대로 의미합니다. 연동 전에 적용하면 "외기가 IGV를 올리고, 그 IGV가 다시 유량을 올리는" 경로와 "외기가 직접 유량을 내리는" 경로가 이중 계산됩니다.

**물리 한계 클램프** — `%` 단위는 0~100, 나머지는 0 이상으로 제한합니다. 순도 100% 초과나 음수 유량 같은 물리적으로 불가능한 값이 검출 엔진의 기준선을 오염시키는 것을 막습니다.

**진동의 물리 여유 검사 (Issue #7)** — 진동을 태우기 전에 물리 한계까지 남은 여유를 확인하고, 상·하 진폭을 각각 그 안으로 제한합니다. 외기·노이즈·연동이 나중에 더해지므로 정상범위 폭의 15%를 그 몫으로 남깁니다.

상한이 물리적으로 막힌 태그(순도)는 여유 제한만으로는 부족해 **하향 편향 진동**을 씁니다. 기저값과 (기저값 − 깊이) 사이에서만 흔들리므로 상한을 절대 넘지 않습니다. O2 순도가 99.6%일 때 위로 갈 여유는 0.4%p뿐이라, 실제 헌팅도 아래로만 크게 흔들립니다.

**검증 결과** (난수 기준값 20260821 로 측정)

| 항목 | 결과 |
| --- | --- |
| 정상 운전 시 **HH/LL**(설비정지 수준) 침범 | **0건** |
| 정상 운전 시 **H/L** 침범 | ⚠ **`LI-806` 1건** — 시나리오를 하나도 주입하지 않아도 최대 89.9 > H 88. 드리프트 3단(정상범위 폭의 12% = ±6.0)이 nominal 80 에 얹혀 **seed 와 무관하게 구조적으로** 넘는다. 나머지 52점은 0건 (기준선 14근무 전수 검사, 2026-08-28). 시나리오 10번의 전제를 무너뜨리므로 아래 「⚠ 알려진 결함」 참조 |
| 시나리오 알람 분류 유지 | **22/22 일치** (미발생 13종 · 발생 7종 · **정상 운전 작업 2종**) |
| 순도 태그 100% 초과 | **없음** — 클램프 없이도 초과 0건 (`AI-707` 최대 99.70 · `AI-803` 99.73 · `AI-807` 99.91) |
| 1번 시나리오를 8개 시간대로 옮겨 L 침범 | **0건** (최소 여유 0.16%p, 15시 주입 시) |
| 탱크 계통 외기 감도 | **전부 0** |
