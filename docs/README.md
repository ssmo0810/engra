# docs — 시나리오 · 모의 데이터 (임도영)

ENGRA 데모용 **가상 ASU(공기분리장치) 플랜트**의 특이 시나리오 정의, 모의 DCS 화면, 태그 마스터입니다.

> **모든 값은 가상입니다.** 사내 실제 태그 체계, 운전값, 시스템 화면과 무관하게 작성했습니다.

## asu_dcs_overview.html 사용법

브라우저로 열면 상단에 두 개의 탭이 있습니다.

- **OVERVIEW PAGE** — ASU 공정 미믹 화면. 설비, 배관(AIR·GN2·LIN·LOX), 컨트롤 밸브, 계측 태그 53점을 배치했습니다.
- **DATA DETAIL** — 태그 마스터 편집 화면.
  - 태그별 **정상값 / 정상범위 / LL·L·H·HH 알람한계**를 입력합니다.
  - **드리프트·노이즈를 1~3단계**로 선택합니다. 태그명을 클릭하면 우측에 60분 파형이 즉시 그려집니다.
  - **연동 태그**란에 상관관계를 적습니다. 형식은 `대상태그:이득:지연초` 입니다.
  - `베이스라인 생성` 버튼으로 seed 고정 raw data(CSV)를 뽑습니다. **seed가 같으면 항상 같은 데이터**가 나옵니다.

## 태그 명명 규칙

**접두 알파벳** — `T` 온도 · `P` 압력 · `PD` 차압 · `F` 유량 · `L` 레벨 · `A` 분석(순도·O₂) · `M` 수분 · `Z` 밸브개도 · `S` 회전수 · `J` 전력

**번호 블록 (3자리, 앞자리가 설비 구분)**

| 블록 | 설비 |
|---|---|
| 100 | Air Filter (F-101) |
| 200 | Air Compressor (K-201) · Motor (M-202) |
| 300 | Adsorber A/B (A-301 / A-302) |
| 400 | Main Heat Exchanger (E-401) |
| 500 | Turbine (X-501) · Generator (G-502) |
| 600 | Cold Box Inlet (FV-601) |
| 700 | HP/LP Column (C-701 / C-702) · 이송밸브 (FV-709) |
| 800 | LOX Tank (TK-801) · LIN Tank (TK-802) |
| 900 | GN2 Supply (PV-902) · Vent (PV-903) |

같은 제어 루프는 번호를 공유합니다. 예: `FV-601`(밸브) ↔ `ZI-601`(그 밸브의 개도).

**단위** — 압력 `bar` · 온도 `℃` · 개도 `%` · 유량 `Nm3/h` · 전력 `kW` · 분석 `ppm` · 회전수 `rpm`

## 베이스라인 데이터 생성 방식

정상 운전 데이터는 세 겹으로 만듭니다.

1. **기저값** — 태그별 정상 운전값
2. **드리프트** — 20~60분 주기의 완만한 흔들림 (외기·부하 변동 반영)
3. **측정 노이즈** — 태그별 σ

드리프트·노이즈 크기는 정상범위 폭 대비 비율로 정합니다.

| 단계 | 드리프트 | 노이즈 |
|---|---|---|
| 1 | 2% | 0.5% |
| 2 | 6% | 1.5% |
| 3 | 12% | 3.5% |

노이즈 없는 선형 데이터를 쓰면 이상 탐지가 실제보다 쉬워 보이므로 의도적으로 배제했습니다.

## 태그 간 연동 (물리 제약)

태그가 서로 무관하게 움직이면 현장 관점에서 부자연스럽고, 시나리오의 연쇄 반응도 표현되지 않습니다. 주요 연동 관계를 정의해 두었습니다.

| 원인 | 결과 |
|---|---|
| `ZI-601` 개도 ↑ | `FI-602` 유량 ↑ , 20초 후 `PI-604` 압력 ↓ |
| `ZI-709` 개도 ↑ | `FI-710` 이송유량 ↑ , 60초 후 `LI-701` ↓ , 90초 후 `LI-705` ↑ |
| `PDI-303` 차압 ↑ | 5분 후 `MI-302` 후단 수분 ↑ (흡착제 파과 징후) |
| `AI-707` LP 순도 ↓ | 3분 후 `AI-803` LOX 탱크 순도 ↓ |
| `PI-203` 토출압 ↑ | `JI-206` 소비전력 ↑ , `TI-205` 토출온도 ↑ |
| `ZI-905` Vent 개도 ↑ | `FI-906` 벤트유량 ↑ , 20초 후 `PI-901` 공급압 ↓ |
