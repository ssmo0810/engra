## 3. 오프라인 대비 — 실측 (현장 네트워크가 죽었을 때)

제출한 소스 zip 을 풀어 노트북에서 돌린 결과. **네트워크 없이 6초** 안에 화면이 뜬다. 어느 폴더에서 치든 상관없다(절대 경로).

```
unzip 소스스냅샷_engra_<해시>_앙그라쥬.zip -d ~/engra_offline
python3 ~/engra_offline/app/cli.py init                                       # 0초
python3 ~/engra_offline/app/cli.py ingest <03 폴더의 asu_shift_day_12h.csv>    # 3초
ENGRA_LLM=off python3 ~/engra_offline/app/cli.py run 2026-08-21-day           # 3초 · 이벤트 40건 · 초안 9항목
python3 ~/engra_offline/app/cli.py serve                                      # http://127.0.0.1:8000
```

- 화면 `/` `/pipeline` `/draft` `/shift/…` `/admin` `/dcs` 전부 200 실측.
- **AI 를 켜고 돌리려면** 노트북 Claude CLI 가 답해야 한다 — 09-11 실측 `claude -p` 응답 6초, exit 0. 결선 당일 아침에 한 번 더 확인.
- ⚠ 오프라인본은 **확정 일지가 0건**이라 「과거 조치」가 안 보인다. 그걸 보여주려면 위 run 뒤 `approve` 를 두 근무 하고 세 번째를 다시 `run` 해야 한다(HANDOFF 순서). 라이브가 살아 있으면 라이브를 쓴다.
- 미리 해 둘 것: 결선 전날 `~/engra_offline` 을 위 순서로 만들어 두고 **승인 2건까지 해둔 상태**로 남긴다. 현장에서는 `serve` 만 치면 된다.
