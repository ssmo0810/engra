## ⑦ 시각 정밀도 — 외부 검토 지적으로 추가 (2026-08-29)

「포함률 100%」 만 내면 **검출 구간이 얼마나 넓은지**가 감춰진다. 시간축(초 단위)으로도 낸다.

| 항목 | `data/` 2근무 | `data/sim` 6근무 |
| --- | --- | --- |
| 검출 지연 중앙값 | **−2분** | **−0분** |
| 주입 뒤에 잡은 것 | 6/22건 (최대 +49분) | 15/46건 (최대 +115분) |
| 시간축 재현율 | 0.86 | 0.87 |
| **시간축 정밀도** | **0.46** | **0.49** |
| 시간축 F1 | 0.60 | 0.63 |

- **지연이 음수**인 것은 추세형 창이 주입보다 먼저 열리기 때문이다. 대부분 주입 시작
  시점이나 그 이전에 이미 창이 열려 있다
- **정밀도 0.46 은 검출 구간이 정답의 2.2배를 덮는다**는 뜻이다. 넓게 잡는 성질을 정면으로
  드러내는 숫자라 **감추지 않고 같이 낸다**
- 2026-08-29 에 드리프트 보고 구간을 CUSUM 으로 좁혀 정밀도 0.40 → 0.46, 검출 지연
  중앙 −34분 → −0분 이 됐다. 검출 여부는 안 바꾸고 보고 구간만 좁힌 것이다

## 쓸 때 반드시 함께 밝힐 것

1. **가상 DCS 데이터다.** 실제 공정 데이터가 아니다. 먼저 밝히면 강점이 되고,
   심사위원이 먼저 찾아내면 약점이 된다
2. **정답지도 우리가 만들었다.** 다만 채점이 헐겁지 않은지는 실측했다 —
   정답지를 60분 옮기면 포함률이 **100% → 75%** 로 무너진다
3. **실제 데이터에서는 낮아질 수 있다.** 그 검증이 Phase 1 이다
4. **IoU 는 세 줄을 다 낸다.** 전체를 빼고 국소형만 쓰면 숫자를 고른 것이 된다
