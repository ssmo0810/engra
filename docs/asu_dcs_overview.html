태그를 선택하세요

왼쪽 표에서 태그명을 누르면 그 태그의 60분 베이스라인 파형을 여기서 미리 봅니다. 드리프트·노이즈 단계를 바꾸면 즉시 다시 그립니다.

드리프트 1 완만 · 2 보통 · 3 큼 — 정상범위 폭의 2 / 6 / 12%
노이즈 1 정밀 · 2 보통 · 3 거침 — 정상범위 폭의 0.5 / 1.5 / 3.5%

연동 태그 예: FI-602:0.95, PI-604:-0.4:20
이 태그가 정상값에서 벗어난 만큼 대상 태그를 이득배로 따라 움직입니다. 세 번째 숫자는 반응 지연(초).

연결 규약 준수 — 내보내기 형식은 timestamp,tag,value CSV · 2초 주기 · 12시간 1근무입니다 (app/README.md). 버튼을 누를 때마다 다음 근무가 생성됩니다 — 주간(06~18) → 야간(18~06) → 다음날 주간 … 이상은 근무 경계를 넘어 이어질 수 있고, 같은 태그에서 동시에 일어날 수도 있습니다. 정답지는 별도 파일로 분리합니다.

주입 설정

시작 일시는 첫 근무에만 적용됩니다. 이후에는 12시간씩 자동으로 넘어갑니다.

아직 생성하지 않았습니다

시작 일시와 방식을 정하고 좌측 버튼을 누르세요.

파일 저장은 GitHub Pages 주소에서만 됩니다. 아티팩트 미리보기 화면은 브라우저가 다운로드를 차단합니다.

과거 기록

CSV 는 최근 3근무만 다시 받을 수 있습니다. 그 이전 근무는 같은 seed 로 처음부터 다시 돌리면 동일한 데이터가 재생성됩니다.
